# BEYONDER Grundskills-Begleiter

Richten Sie mit Claude oder ChatGPT drei persönliche Grundskills ein: Ihre Firmenstimme, Ihre persönliche Stimme und Ihr Branddesign. Der Begleiter führt Sie Schritt für Schritt durch die Einrichtung.

## Starten

1. [Kundenpaket herunterladen](https://github.com/BEYONDERnow/grundskills-begleiter/releases/download/v0.2.3/BEYONDER-Grundskills-Kundenpaket-v0.2.3.zip).
2. ZIP öffnen und das Startblatt lesen.
3. Die Begleiter-Datei in einen neuen Chat legen und schreiben: „Starte den BEYONDER Grundskills-Begleiter.“

[Startblatt separat als PDF herunterladen](https://github.com/BEYONDERnow/grundskills-begleiter/releases/download/v0.2.3/Startblatt-Kundschaft.pdf)

Die Möglichkeiten zum Speichern und Aufrufen der Skills hängen von Konto und Oberfläche ab. Das Startblatt erklärt den Einstieg.
